# Приложение - Таро Гадание

Личный pet-проект - приложение для гадания на картах Таро. Делал для практики фронтенда, создания структуры проекта, архитектурных решений. В приложении есть: выбор типа и цели расклада, раскрытие карт, толкование через ИИ сервис, карта дня, дневник сохранённых раскладов с фильтрацией.

**Демо:** [\[ссылка на Vercel\]](https://tarot-app-woad.vercel.app)

## Стек

### Основа
- **React + TypeScript** - весь проект изначально был на JS, TS добавил уже после того, как была написана основная логика. Часть типизации (интерфейсы сущностей, discriminated union для записи дневника `spread | dailyCard`, типы для Redux state) делал сам, разбираясь по ходу с тем, как типы должны раскладываться по FSD-слоям. Более сложные места - например, вывод типов через `useInfiniteQuery` с кастомным `pageParam`, generic-функция `generateTarotMeaning<T>` с условным типом результата разбирал вместе с ИИ, потому что это слишком специфичная и сложная часть.
- **Vite** - сборка, алиасы путей (`@/`), `vite-plugin-checker` для проверки типов и линта прямо в дев-сервере

### Состояние приложения
- **Redux Toolkit** - глобальный стейт и данные, которые являются основой приложения - типы и цели расклада, карты таро, айди авторизаци итд.
- **TanStack Query** - выбран отдельно для дневника, чтобы реализовать кэширование, пагинацию (`useInfiniteQuery`), проверку карыт дня через запрос (для авторизованного пользователя)
- **redux-persist** + **PersistQueryClientProvider** - сохранение айди пользователя и кэша дневника

### Стили
- **SCSS-модули** - каждый компонент со своими стилями. Общие переменные/цвета через `@use`, SCSS плейсхолдеры (`%button` + `@extend`)

### Библиотеки
- **clsx** - условное объединение классов
- **react-spinners** - готовые лоадеры
- **react-router-dom** - роутинг
- **Auth0** (`@auth0/auth0-react`) - авторизация (+ отдельно гостевой режим)

### Данные и внешние сервисы
- **Firebase Firestore** - хранение данных: карты, типы/цели расклада, записи дневника
- **Cloudinary** - хранение изображений карт
- **Cerebras AI** - генерация толкований расклада и карты дня, для всего свой промпт с разными параметрами

## Архитектура

Старался реализовать FSD, бизнес-логика вынесена в кастомные хуки, в компонентах практически только разметка

## Ограничения
- Здесь есть адаптивная верстка, но лучше всего смотреть с десктопа
- Изображения сгенерированы не для всех карт, некоторые будут заменяться локальным изображением
